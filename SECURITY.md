# Security Policy

## Supported versions

StandYouUp is a small menu-bar app; security fixes are applied to the latest
release only.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report privately to **hello@silavapi.co.uk**, or use GitHub's
["Report a vulnerability"](https://github.com/rcheesley/standyouup/security/advisories/new)
private advisory flow.

Include, where possible:

- A description of the issue and its impact
- Steps to reproduce
- The version or commit you tested

You can expect an acknowledgement within a reasonable time, and we'll keep you
updated on the fix and disclosure timeline.

## Scope notes

StandYouUp runs locally, stores its preferences in `UserDefaults`, and makes no
network requests. Please keep that context in mind when assessing impact.
